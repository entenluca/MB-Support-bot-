ANIKBOTHOSTING - KURZANLEITUNG (v1.3.1)
========================================

WICHTIG: Dateien direkt ins Bot-Hauptverzeichnis legen (nicht in einen Unterordner).

1. Alle Dateien aus dem Repo/der ZIP ins Bot-Verzeichnis hochladen:
   index.js, package.json, package-lock.json, .env.example
   (node_modules NICHT hochladen)

2. Node.js 18 oder neuer waehlen (empfohlen: Node.js 22).

3. Im Terminal/Install-Befehl ausfuehren:
   npm install

4. .env.example zu .env kopieren und eintragen:
   BOT_TOKEN=dein_discord_bot_token
   VOICE_CHANNEL_ID=deine_sprachkanal_id

   Alternativ kannst du BOT_TOKEN auch im Hosting-Panel als Umgebungsvariable setzen.

5. Startbefehl im Panel:
   npm start
   (alternativ: node index.js)

6. In der Konsole solltest du sehen:
   "Starte MB ANTENNE 1 Bot ..."
   "Bot online als DeinBot#1234"

FEHLERBEHEBUNG
--------------
Bot startet, bleibt aber offline:
-> BOT_TOKEN pruefen (Token im Discord Developer Portal neu kopieren)
-> .env liegt im gleichen Ordner wie index.js

"Login fehlgeschlagen: An invalid token was provided":
-> Token ist falsch oder abgelaufen -> neuen Token eintragen

"Kein Sprachkanal gefunden":
-> VOICE_CHANNEL_ID pruefen (Rechtsklick auf Sprachkanal -> ID kopieren)

"Kein nutzbares FFmpeg gefunden":
-> npm install erneut ausfuehren

Prozess startet sofort neu / stuerzt ab:
-> Konsole-Log lesen; meist fehlender Token oder falsche Node-Version
